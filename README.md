# Точка

Читалка по одному слову (RSVP): слово стоит на месте, красная буква — точка, куда смотрит глаз. Открывает FB2 (и fb2.zip), EPUB, TXT, PDF. Оглавление, закладки, темы, размер шрифта, тиканье на каждое слово. Работает в браузере и ставится на телефон как приложение; книги хранятся только на устройстве.

## Управление

- Тап по слову или пробел — пауза / чтение
- ← → — на предложение назад / вперёд
- ↑ ↓ — скорость ±25 слов в минуту
- B — закладка, Esc — к библиотеке
- На паузе снизу виден текущий абзац: тап по слову — продолжить с него

## Разработка

```
npm install
npm run dev      # локально
npm test         # тесты
npm run build    # сборка в dist/
```

Иконки: `node scripts/make-icons.mjs` (нужен Chrome).
